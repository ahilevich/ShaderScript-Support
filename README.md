# Shader Script Support

Bug reports, questions and feature requests for [Shader Script](https://ahilevich.github.io/ShaderScript/), the Unity
package for writing URP and HDRP shaders in C#. This repository holds no code: it's where you get help and tell us what
you need.

## Where to go

| You want to | Go to |
|---|---|
| Report a bug | [Issues](../../issues/new/choose): choose **Bug report** |
| Ask how to do something | [Discussions, Q&A](../../discussions/categories/q-a) |
| Suggest a feature | [Discussions, Ideas](../../discussions/categories/ideas), or [Issues](../../issues/new/choose): choose **Feature request** |
| Show what you made | [Discussions, Show and tell](../../discussions/categories/show-and-tell) |
| Hear about new versions | [Discussions, Announcements](../../discussions/categories/announcements): click **Watch** on this repository, or subscribe to the category |
| Anything private, such as refunds or licensing | ahilevich.dev@gmail.com |

Before opening an issue, please search the existing [issues](../../issues?q=is%3Aissue) and
[discussions](../../discussions): someone may have had the same problem. The
[Common problems](https://ahilevich.github.io/ShaderScript/latest/manual/debugging.html#common-problems) section of the
manual covers the most frequent ones.

## Response time

Shader Script is made by one person, so replies aren't instant: you'll usually get one within two working days.
